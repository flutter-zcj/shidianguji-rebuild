## E. 复刻落地建议（uni-app + FastAPI）

1. **路由层**：用 `route_key → {type: lynx|h5, url, options}` 表复刻 54 条 `RedirectRuleMap`；uni-app 侧实现 `openEntry(key, params)`。
2. **Tab 层**：默认 4 Tab（首页/书架/分类/我的），保留 `data_hash + page_list + bottom_bar_schema + recommend_page_schema` 结构以便服务端换 Tab。
3. **版本三元组**：`version`（正文）、`metaVersion`（元数据）、`pinYinVersion`（拼音）、`audioVersion`（音频）、`volumeVersion`（卷）—— 离线缓存与增量更新全部依赖，务必照搬。
4. **图片参数**：统一 `ImgConf{resizeWidth, qvalue, isWebpSupported}`。
5. **通用收藏**：`favorites` 系列用 `bizType + bizId` 抽象（名句、书籍共用）。
6. **书架多用**：`shelfBizType` 让书籍/视频/课程共用一张书架表；V4 接口已统一为 `items[]` 批量结构，建议直接采用。
7. **阅读器**：正文按「段落数组 + contentType 位标记」下发（一段同时含原文/注疏/译文/底本原字，前端按 `showFlag` 位运算决定显示），显著减少请求数，建议保持。
