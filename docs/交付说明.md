> 目标：反编译「识典古籍」Android App（`com.shidianguji.android`），用 **prjtmpl（uni-app）** 复刻前端、
> 用 **RuoYi-FastAPI 的 `module_guji`** 提供后端，尽量还原全部功能。

## 一、逆向分析结论（产物在 `/workspace/guji/`）

| 环节 | 手段 | 结果 |
| --- | --- | --- |
| DEX 字符串 | 自研 `tools/dex_strings.py` 解析 `string_ids`（`dex\n038`，偏移 `0x38/0x3C`） | 7 个 dex，约 36 万条去重字符串 → `analysis/strings/` |
| Java 反编译 | jadx 1.5.2 反编译 `classes5.dex` | 558 个 `com/shidianguji/android/*.java` → `analysis/jadx/` |
| 离线包 | `assets/gecko_build_in/**/res.zst` 用 zstd 解压 → zip | Lynx 页面 **27** 个、H5 页面 **31** 个（含 `read`/`search`/`topic`/`readlist`/`logged`/`ai` 等）→ `analysis/gecko/` |
| 接口注册表 | 从 bundle 正则 `(0,c._)(r,"METHOD /path","fnName")` | **557** 条（C 端 287 + 后台 279）→ `analysis/api_registry.json` |
| 页面与实体模型 | 综合比对 | `analysis/REPORT_PAGE_MODEL.md`（386 行） |

### 关键技术发现

- **混合容器**：字节 AnnieX，`sslocal://lynxview`（Lynx 27 页）/ `sslocal://webview`（H5 31 页），
  JSBridge 由 `AbsGuji*MethodIDL` 定义共 **57** 个方法，Gecko 支持热更新。
- **接口族**：`/api/ancientlib/read/**`（阅读、书架、书签笔记）、
  `/api/ancientlib/app/**`（首页、讲书、视频）、`/api/ancientlib/dict/**`（字典、实体）、
  `/api/ancientlib/mgt/**`（后台）。
- **主 Tab**：home / bookshelf / category / mine 四个。
- **内容模型**：书名 → 卷 → 章 → 段 四级；段落用 `contentType` 位标记，
  原文/译文/注疏/校勘 **同段下发**，前端按位渲染。
- **版本三元组**：`version / metaVersion / pinYinVersion / audioVersion / volumeVersion`。
- **书架多用化**：`shelfBizType` 区分书/音频/讲书；收藏用通用 `bizType + bizId`。
- **首页字段压缩**：Lynx bundle 内有 100 项字段名压缩字典 `sS`，已还原映射。
- 当前版本**无全局竖排**排版，仅部分页面支持（前端设置页已预留开关）。

## 二、后端：`ruoyi-fastapi-backend/module_guji`

| 项 | 数量 |
| --- | --- |
| 控制器 | 10 个 |
| 路由 | **227** 个 |
| 数据表 | **41** 张 |
| 代码量 | 约 8000 行（controller + service + dao + entity） |

- 路由前缀：`/api/ancientlib/read`（book / bookshelf / history / note / quotation / search / topic / user）、
  `/api/ancientlib`（dict / media）。
- 自动注册：框架 `APIRouterPro` 扫描 `*/controller/[!_]*.py`。
- 鉴权 `aspect/guji_auth.py`：`X-User-Id` > `guji_<id>` 令牌 > JWT > 游客（user_id=0）。
- 会话 `aspect/guji_session.py`：`GujiDbSession` 在 yield 后自动 `commit`，异常 `rollback`

- 示例数据 `scripts/init_guji_db.py`：论语 / 道德经 / 史记 / 陶渊明集，各 4 章 × 若干段，
  含名句、音频、讲书系列、视频、Banner、推荐位、通知。

## 六、真实数据迁移（线上库）

服务器 `zbcx_sj` 库里本就有一批 Gutenberg 中文古籍（`gj_book` 244 本 / `gj_chapter` 4339 章 / 3232 万字），
已通过纯 SQL 迁移进新模型，替代原先的 4 本示例数据：

| 表 | 迁移后 |
| --- | --- |
| `guji_category` / `guji_book` / `guji_volume` | 5 / 244 / 244 |
| `guji_chapter` | **15039**（迁移后做了拆分，见下） |
| `guji_paragraph` | **691241** |
| `guji_quotation` | 51（名句白名单匹配 32 + 规则补足 19） |
| `guji_recommend` / `guji_homepage_banner` / `guji_notice` | 12 / 2 / 3 |

迁移脚本：`module_guji/scripts/migrate_real_data.{py,sql}`、`seed_quotations.sql`、`polish_data.sql`。

两处数据打磨：

1. **重建章节目录**：迁移后有 124/244 本书整书只有一个「全篇」章节，目录页形同虚设。
   按「短行、无句读、无引号、无数字」规则在内文中识别标题重新分章，
   章节数 4339 → **15039**，单章书 124 → **5**，段落数不变（无丢失）。
   《论语》已正确拆出「学而第一 / 为政第二 / 八佾第三…」21 章。
2. **清理英文元数据**：Gutenberg 的英文简介（如 `Ethics -- China`）改写为中文描述，
   共 234 本；被误判为标题的英文版权行统一归到「版权与校记」并排到末尾。

## 七、已知边界

- **听书 / 讲书为空**：线上库没有音频与视频数据，`guji_audio`、`guji_video` 为空表，两页显示空态。
  页面与接口本身可用，灌入数据即可展示（示例数据的音频地址是占位 URL，不指向真实媒体）。
- AI 助手为基于古籍库的检索式回答（未接大模型），需接 LLM 时替换
  `service/guji_user_service.py` 的 `assistant_chat`。
- 竖排排版开关已在设置页预留，渲染层尚未实现竖排布局。
- 登录为 `X-User-Id` 调试态，未做真实账号体系与短信/第三方登录。
- 段落按换行切分，个别书籍的章节标题行可能混在正文中；《道德经》等书的章节名是首句截断（长度 24 以内），非标准篇名。
