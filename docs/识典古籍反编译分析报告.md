## 4. 网络接口清单（Base URL：`https://www.shidianguji.com`）

### 4.1 阅读核心接口

**POST `/api/ancientlib/read/book/paragraphs/v3/`** — 获取章节段落（阅读器核心）

请求参数（`ParagraphRequest`）：
```json
{
  "bookId": "字符串，必填",
  "chapterId": "字符串，必填",
  "paragraphId": "字符串，可选；为空时按 currentPage 分页",
  "pagination": { "pageSize": 200, "currentPage": 1 },
  "forwardParaNum": 0,
  "writeCache": true,
  "needRawData": true
}
```
返回（`ParagraphsResponse`）：`ParagraphsPage` 分页结构，含段落列表（`Paragraph`：段落序号、文本、层级）。

### 4.2 阅读历史

## 5. 重建工程方案（本工程）

基于反编译分析结论，使用用户指定技术栈重建一套功能等价的古籍阅读平台：

### 5.1 前端（prjtmpl 模板：Vue3 + uni-app + uview-plus）

| 页面 | 对应原版功能 | 说明 |
|---|---|---|
| `pages/login/index` | 账号登录 | 对接后端 JWT 登录 |
| `pages/index/index`（首页 Tab） | Lynx home 模板 | 推荐书目列表 + 搜索入口 |
| `pages/bookshelf/index` | Lynx shelf 模板 | 书架（最近阅读、收藏书目、阅读进度） |
| `pages/category/index` | Lynx category 模板 | 古籍分类（经/史/子/集 + 朝代） |
| `pages/mine/index` | Lynx logged 模板 | 我的（个人信息、阅读历史、听书记录） |
| `pages/book/detail` | 书目详情 | 书籍信息、章节目录、开始阅读/加入书架 |
| `pages/reader/index` | 原生阅读器 | 章节段落阅读（分页 + 前后翻页） |
| `pages/history/index` | 阅读历史 | 历史列表 |

### 5.2 后端（RuoYi-FastAPI backend）

业务模块 `module_guji`（古籍平台）：

| 模块 | 表 | 说明 |
|---|---|---|
| 书目 | `guji_book` | 古籍书目（书名/作者/朝代/分类/简介/封面/章节数） |
| 章节 | `guji_chapter` | 章节（所属书、序号、标题） |
| 段落 | `guji_paragraph` | 段落内容（所属章节、序号、文本） |
| 书架 | `guji_bookshelf` | 用户书架（用户、书目、进度、收藏时间） |
| 历史 | `guji_read_history` | 阅读历史（用户、书、章节、段落、时间） |
| 音频 | `guji_audio` | 听书音频（书、章节、音频 URL） |

复用 RuoYi 用户/权限体系（`sys_user`、`sys_role`、JWT OAuth2 登录），新增业务 CRUD + 分页 + 阅读进度上报/获取。

### 5.3 接口设计（前后端约定）

```
POST /guji/login                     登录（复用 RuoYi 登录接口 /login）

GET  /guji/book/{id}                 书目详情
GET  /guji/book/{id}/chapters        章节目录
GET  /guji/chapter/{id}/paragraphs   段落分页（pageSize/currentPage 模拟 v3 接口）
POST /guji/bookshelf                 加入书架
GET  /guji/bookshelf                 书架列表（含进度）
DELETE /guji/bookshelf/{id}          移出书架
GET  /guji/history                   阅读历史

```
